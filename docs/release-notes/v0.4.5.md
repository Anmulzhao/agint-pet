宠物插件随 dsh-web 家族对齐到统一版本。本版本新增两只宠物，修好主开关与宠物自身隐藏意图的冲突，并让设置表单延迟绑定，不再在 apply() 阶段只探测一次。

### 新功能

- 新增 frames2d 宠物 jyn-foxtail（#5）
