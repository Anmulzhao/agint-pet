This release adds the built-in pet deep-chan: a sprite2d pixel-art character contributed by Daizhdd, cut from an 8x9 atlas of 256x288 cells (2048x2592, 57 frames), 49 of them standalone per-frame artwork, which brings the built-in set to 12 pets. It also fixes issue #17, where the pet dropped the whole GUI's frames for as long as it was on screen: the sprite render path no longer runs on a 60 fps `requestAnimationFrame` loop, atlas placement lands on whole pixels, and the invisible yet re-composite-forcing `backdrop-filter` on three bubbles is gone. The rest is what the new pet needed: the registry's expected ids, the bilingual README rows, third-party provenance and a PR evidence directory.

> **Compatibility**: nothing breaks. The package name `@linxin666/dsh-pet`, the install path, the host floor declared in `dsh.engines.dsh`, the layout persisted in `$DSH_HOME/pet.json` with its keys, and every wire-protocol field keep their names and meaning, so no manual migration is needed.

### New Features

- New built-in pet deep-chan, sprite2d pixel art: an 8x9 atlas of 256x288 cells (2048x2592, 57 frames), 49 of them drawn as standalone per-frame artwork, the 8-frame walk cycle and the 5-frame jump each an independent pose, the remaining states varying by expression and small motion, plus the 8 running-left frames mirrored horizontally from running-right; `license: Personal-Use-Only`, and `node scripts/dsh-pet.cjs validate assets/deep-chan` passes (#15)
- deep-chan is an unofficial, fan-made derivative of the DeepSeek whale girl (鲸鱼娘): the character and all related rights belong to DeepSeek, this is fan artwork with no affiliation to or endorsement by DeepSeek, and the assets are personal non-commercial use only; `THIRD_PARTY_NOTICES.md` and both READMEs record the source and the limits
- Like `jyn` / `jyn-foxtail` / `doro` / `jyn-loli` it stays repository-only and out of the `package.json` `files` whitelist, so the installed size of `@linxin666/dsh-pet` is unchanged

### Bug Fixes

- Issue #17: the built-in `whale-girl-refined` pet (a 1536x1872 atlas, about 11 MB once decoded) at `display.size: 160` dropped frames across the whole GUI, and hiding the pet restored them. `src/client/spritesheet.ts` now quantizes the scaled cell size once (`scaledCellSize`) and derives both `framePosition` and `background-size` from it, so the atlas grid, the sprite box and every frame offset share one pixel grid. The cell used to render at 147.69 x 160 px with a 1181.5 x 1440 px `background-size`, so every frame change landed on a fractional pixel boundary and the compositor could only re-filter the scaled atlas; a frame change is now a whole-pixel translate of the scaled atlas
- The frame loop in `src/client/PetSprite.tsx` is scheduled by the current frame's remaining time (`src/client/sequences.ts` gains `remainingAt`) instead of `requestAnimationFrame`, and a non-looping track stops waking once it holds its final frame; a scale change still repaints the settled frame
- The roam walk writes the float's right / bottom directly and keeps the live spot in a ref instead of a `setState` on every animation frame: React state updates once, on the landing frame, and a drag grabbed mid-walk starts from the position the pet actually reached
- `src/client/pet.module.css` drops `backdrop-filter` from the status bubble, the announcement bubble and the hover panel. All three are 90-97% opaque, so the blur was not visible while forcing the region behind them to re-composite on every sprite frame change

### Other Changes

- `src/registry.test.ts` gains `deep-chan` in its alphabetical slot, the bilingual built-in pet table gains the matching row, and `README.i18n.yaml` re-records the pair hashes
- New PR evidence directory `docs/pr-evidence/deep-chan-pr-15/`: the Settings pet selector screenshot and this round's review record
- Agent Notes: issue #17's sprite render-path costs and the one suspicion that did not apply, plus the 2026-10-17 pet review round
- Tests: a new `src/client/spritesheet.test.ts` (atlas geometry), `remainingAt` coverage in `src/client/sequences.test.ts`, whole-pixel atlas size, a frame loop without rAF, a settled track that stops waking, scale repaint and a walk that does not re-render in `src/client/PetSprite.test.tsx`, and a CSS guard against `backdrop-filter` in `src/client/pet-css.test.ts`
