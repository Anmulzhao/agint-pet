## 1. 这个 fork 存在的理由

上游 `dsh-pet` 已经装在这台机器上并且在跑。本 fork 不改它的功能，只做两件事：

1. **分发 AGINT 桌宠素材**（`assets/agint/`），并让受限内置资产不外流。
2. **当上游同步的缓冲区**。上游发新版时 `git fetch upstream` 加重基。

不做的：改宠物玩法、改渲染器、**改 `src/` 任何一行**、加 AGINT 逻辑进 `src/`。

⚠️ 「要改宠物插件行为时在这里改」这条旧说法已作废（2026-10-05）。
本仓 `src/` `contracts/` `scripts/` **与上游逐字节相同**（`git diff upstream/main..HEAD -- src/` 为空），
这是本仓能低成本重基的前提。**要加 AGINT 行为，做成主仓的独立插件**，
跨插件调 `ctx.pet.announce()` / `ctx.pet.setSkin()`。理由见主仓
`docs/brand/agint-pet-repo-relation.md` §1。

**轨道为什么是摆动而不是整圈旋转**（老板 2026-10-04 裁定）：慢速旋转与闭合轨道在数学上互斥
（5°/帧要 72 帧才闭合，1.5°/帧要 240 帧），循环时末帧跳回首帧的锯齿被眼睛读成方向反转。
故四个相位改用**三角摆动**（−A→+A→−A，末帧=首帧，构造性闭合），并统一为**顺时针**。
`done` 保留 45°×8=360° 的整圈（唯一本来就闭合的整圈相位），`failed` 静止。

### 从本仓安装 assets/agint

⚠️ **先分清两件事**：本仓是**素材源**，宿主**不会**自动读它。
`dsh web` 跑的是它自己 profile 里的 `@linxin666/dsh-pet` npm 包，那个包的 `assets/`
与本仓无关。**帧要生效只有一条路：装进 `$DSH_HOME/pets/<id>/`。**

```sh
# 0. 先验（不装也该跑）
node scripts/dsh-pet.cjs validate assets/agint
# 期望：valid: agint (renderer frames2d)

# 1a. 走校验器安装（推荐：会先校验再拷，失败不覆盖）
node scripts/dsh-pet.cjs install assets/agint --force

# 1b. 或直接拷（本机沙箱下校验器的 cpSync 曾静默失败，实测走这条）
cp -r assets/agint "$DSH_HOME/pets/agint"

# 2. 复验：安装位帧数与逐字节一致性
node scripts/dsh-pet.cjs validate "$DSH_HOME/pets/agint"
```

**目录名必须等于 `manifest.id`**（= `agint`）。实证 `dsh-pet install` 用 `manifest.id`
建目录（`scripts/dsh-pet.cjs`），注册表用 `pet.json` 的 `id` 索引（`src/registry.ts`）。
两边不一致会建出第二个目录，选择器出现两条。

**装完不必重启 dsh。** 帧由宿主从磁盘直读、经 HTTP 供给前端（`cache-control: no-cache`），
刷新页面即可。实测安装位 57 帧与本仓逐字节一致、宿主 HTTP 取回的也是同一批字节。
⚠️ 但上游 README 写「注册表在宿主启动时构建一次，改宠物后要重启 `dsh web` 生效」——
**两句冲突，以实测为准**（2026-10-05 实测 57/57 字节一致，未重启）。若遇到列表里看不到新宠物，
再重启也不失为兜底。

**`package.json` 的 `files` 白名单必须含 `assets/agint`**，否则 `npm pack` 会把 57 帧全漏掉
（仓库里有、包里没有）。2026-10-05 已补上。
