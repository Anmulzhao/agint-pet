# Agent Note: SDK cohort 0.2.1-rc.3

Status: implemented

## Problem

The pet plugin tracked 0.2.1-rc.2 while the supported host moved to 0.2.1-rc.3. The new host changes composer draft initialization and submission state, two areas adjacent to the pet's session activity projection, so the update must establish whether the existing event and settings surfaces still hold.

## Decision

All consumed SDK development dependencies move to `^0.2.1-rc.3`, preserving this repository's caret-range convention and the lockfile as the resolved-version record. `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer both move to `>=0.2.1-rc.3`; the bilingual README badges and pairing record follow. Cordis `~4.0.5` and schemastery `~3.18.5` remain aligned with the cohort.

The `packageExtensions` repairs for `dsh-client-store` and `dsh-client-ui-primitives` are re-keyed to rc.3, including the two DeepSeek utility pins. The lockfile and release-age ledger cover all 29 resolved rc.3 packages with no missing exclusion.

The upstream draft changes are additive at the consumed surface: `DraftInitializationOptions.whenDraftExists` is optional, and the pet does not implement `MessageSubmissionState` or the new conversation-header owner. The agent and durable session event declarations used by the activity projection have no rc.3 source change. The eleven-row browser platform table is unchanged, so only its provenance comment moves. No runtime source adaptation is needed.

## Alternatives considered

**Stay on rc.2 because the API changes are additive.** Rejected: the declared host floor and development cohort must name the host against which the plugin is actually adapted and tested.

**Rewrite pet draft or submission calls to consume every new field.** Rejected: the new fields are optional for this plugin's contracts, and manufacturing draft behavior or analytics state would change product behavior without a requirement.

**Change the package version or publish the cohort update immediately.** Rejected: this is a compatibility change owned by the repository, not an explicit release request.

## Consequences

`pnpm install --frozen-lockfile --ignore-scripts`, `pnpm typecheck`, `pnpm test` (679 tests), the `scripts/dsh-pet*.test.mjs` node gates (22 tests), and `pnpm build` pass. The rebuilt committed `lib/` is unchanged.

No `@linxin666` version changes and nothing is published to npm. The repository owns its cohort commit; dsh-web moves the submodule pin after the commit is available on this repository's remote `main`.
